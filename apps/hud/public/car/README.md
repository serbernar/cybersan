# Рендери автомобіля

Якщо покласти сюди `manifest.json` і картинки, HUD візьме їх замість вбудованого
малюнка. Жодного коду міняти не треба.

```json
{
  "base": "base.webp",
  "lights": "lights.webp",
  "doors": {
    "driver": "door-driver.webp",
    "rearLeft": "door-rear-left.webp",
    "tailgate": "door-tailgate.webp"
  }
}
```

Вимоги до шарів:

- однаковий розмір полотна й однакова позиція авто на всіх шарах — вони кладуться
  один на одного;
- `base` — непрозорий рендер машини на прозорому фоні;
- решта шарів — тільки те, що додається: світло фар, підсвічені двері. Вони
  проявляються поверх бази.

Формат — WebP або PNG з альфа-каналом. Ширина 1600 px з запасом вистачає:
на панелі авто займає близько 600 px.

## Звідки взяти модель

Потрібна модель із ліцензією, яка дозволяє використання — наприклад CC-BY на
Sketchfab або куплена на TurboSquid. Зображення з пошуку Google брати не можна:
це чужі роботи під авторським правом.

Далі в Blender: камера збоку, ортографічна проекція, м'яке верхнє світло, рендер
із прозорим фоном. Кожен стан — окремий рендер тієї ж сцени: базовий, з
увімкненими фарами, з відчиненими дверима.
