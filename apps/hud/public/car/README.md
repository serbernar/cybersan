# Модель автомобіля

Тут лежить 3D-модель, яку HUD показує в картці авто.

```
model.glb    сама модель (glTF binary)
model.json   як її поставити й розфарбувати
```

Нічого підключати не треба: якщо `model.glb` на місці, HUD бере його. Якщо
файлу немає — малює власну процедурну модель T30 (`src/components/car/t30.ts`),
а без WebGL узагалі — плаский SVG.

## model.json

Усі поля, крім `file`, необов'язкові.

```json
{
  "file": "model.glb",
  "credit": "автор і ліцензія",
  "length": 4.455,
  "yaw": 0,
  "mirror": true,
  "keepMaterials": false,
  "materials": { "body-color": "paint", "glass1": "glass" }
}
```

- `length` — довжина авто в метрах. Модель масштабується під неї, тож байдуже,
  в яких одиницях її зробили. Для T30 це 4.455.
- `yaw` — градуси повороту, якщо машина дивиться не туди. Довжину вздовж осі X і
  посадку на «землю» HUD вирівнює сам.
- `mirror` — віддзеркалити машину вздовж. Безкоштовні моделі T30 переважно
  японські, праворульні; у нас кермо ліворуч. Дзеркалення запікається в
  геометрію (з розворотом намотки трикутників), а не робиться від'ємним
  масштабом, інакше поламається світло.
- `materials` — відповідність матеріалів моделі до ролей у палітрі HUD:
  `paint`, `glass`, `tyre`, `rim`, `trim`, `clad`, `headlamp`, `foglamp`,
  `indicator`, `reverse`, `taillamp`. Що не вказано — вгадується з назви.
- `nodes` — те саме, але для окремих вузлів, коли матеріал завеликий гребінець:
  протитуманки цієї моделі відлиті з того самого чорного пластику, що й бампер.
  Має пріоритет над `materials`.
- `hide` — вузли, які не показувати (у цій моделі це японський маркер на крилі).
- `keepMaterials: true` — лишити рідні матеріали моделі замість перефарбування
  в кольори теми. Тоді машина не змінюватиметься між нічною й денною темою.

Двері, якщо вони не названі в моделі, HUD знаходить за формою: тонка висока
панель на борту між осями. Відчинені підсвічуються червоним. Скло, що лежить у
межах дверей, стає вікном і опускається вниз на відсоток із контракту; кватирки
й нерухоме скло лишаються на місці, бо не належать жодним дверям.

Уся ієрархія моделі при завантаженні «розпрямляється» у світові координати:
кожен меш отримує геометрію в метрах без власних трансформацій. Без цього вікно
їхало б уздовж локальної осі меша — тобто вбік, а не вниз.

## Своя модель

Потрібна ліцензія, яка дозволяє використання — CC-BY на Sketchfab або куплена на
TurboSquid. Картинки з пошуку Google брати не можна: це чужі роботи під
авторським правом. Формат — GLB; у Blender це `File → Export → glTF 2.0 (.glb)`.

## Замість моделі: готові рендери

Якщо WebGL на цільовому залізі не тягне, сюди можна покласти `manifest.json` і
картинки-шари — HUD віддасть перевагу їм.

```json
{
  "base": "base.webp",
  "lights": "lights.webp",
  "doors": { "driver": "door-driver.webp", "tailgate": "door-tailgate.webp" }
}
```

Однакове полотно й однакова позиція авто на всіх шарах, прозорий фон, `base` —
машина цілком, решта — тільки те, що додається поверх. WebP або PNG з альфою,
ширини 1600 px вистачає з запасом.
